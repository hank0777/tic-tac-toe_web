# React Tic-Tac-Toe
This project started from the official React Tic-Tac-Toe tutorial and was expanded with additional features and more advanced game logic.

## Features
- Game controls (undo, redo, restart)
- Multiplayer and single-player modes
- Multiple difficulty levels
- Optimal AI for hard difficulty using the Minimax algorithm

### Running the Project
Follow these steps to run the app locally:

```bash
npm install
npm start
```

or on Windows:
```bash
npm.cmd start
```
Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.
